# FATHIMIX Script Writer

Write original Hindi scripts for Zeesh's GTA 6 faceless explainer channel
**FATHIMIX**. Use whenever Zeesh asks for a new GTA 6 video, a script, or the
next video in the series. Agent builds the full pack; Zeesh uploads (Unlisted
until he says Public).

## Locked channel rules (owner-set, do not re-ask)
- **Hook-study first:** before writing, run **fathimix-viral-decoder** on
  ColeTheMan's video on the same topic. Script follows that flow (hook,
  structure, coverage order) in ORIGINAL Hindi — his lines are never copied.
- **Hook lands in the first 5–10 seconds.** No intro card, no slow start.
  Pick the hook type from `hooks-bank.md` in this folder and adapt it.
- **Accuracy:** every claim labelled CONFIRMED or RUMOUR in the fact sheet;
  leak-based claims are never stated as confirmed in the script.
- **Length:** standard deep-dive 8–13 min (~1,200–2,000 Hindi words at natural
  speaking pace); mega-guides up to ~18 min (~2,700 words). Fewer, longer
  videos — never pad a thin topic.
- **Thumbnail text is NOT used inside the video.**
- **Titles:** ColeTheMan style — full English, curiosity gap, ONE keyword in
  CAPS. Every pack carries BOTH options: (A) Cole English title, (B) hybrid
  English + Devanagari hook title. Zeesh picks at upload.
- **Description:** short, punchy English lines only.
- **Pinned comment:** Hindi.
- **Video specs:** master 1080p AND upload/link copy 1080p, link copy ≤97 MB.

## Workflow
1. Decode the reference video (see above) and build the CONFIRMED/RUMOUR
   fact sheet.
2. Choose the hook (hooks bank) and the one big promise of the video.
3. Outline: hook (5–10s) → promise/payoff tease → sections in the reference
   flow, each ending on a mini-cliffhanger → strongest payoff saved near the
   end → short closing + next-video tease.
4. Write the full script in natural spoken Hindi. Conversational, fast,
   no filler greetings, no "welcome back to my channel" openings.
5. Assemble the delivery pack:
   - Full script (with section markers + approx. timestamps)
   - Fact sheet (CONFIRMED / RUMOUR)
   - Both title options (Cole English + hybrid)
   - English description (short punchy lines)
   - Hindi pinned comment
   - Thumbnail brief → hand to **fathimix-title-thumbnail**
6. Save the pack under `~/workspace/your_files/fathimix/` in its own
   video folder, then build the video per the standing production flow.
