# Search Console Index Reporting

## Name the scope before you quote a number

- Read the number from the Pages view when the question is how many pages are indexed, and read the Queries view only when the question is which queries drove clicks.

- Quote a sitemap total only with the words sitemap view beside it, and quote a property total only with the words property-wide beside it.

- Never add a sitemap numerator to a property denominator, and never compare a sitemap figure with a property figure as if they were the same count.

- When the user gives a number that differs from yours, ask which view it came from before you correct it, and then state both figures with their views named.

- When two figures disagree, report both with their scopes and explain the gap in one line instead of picking one silently.

## Report only what you actually opened

- Say that a figure came from a screenshot the user sent when that is how you saw it, and never say you read an inbox or an account you did not open.

- Say that you did not open Search Console when you did not open it, and name the source you did use instead.

- Never claim a page was recrawled or a fix was verified live unless you checked the live page or the crawl date yourself.

- When a check is blocked, name the blocker and the step that would unblock it instead of reporting the number as if the check had run.

## Date every claim about change

- Check the last crawl date before you say new content has been seen by Google, and say the content is still waiting on the next crawl when the crawl predates the change.

- Give the date range beside every clicks and impressions total, and never present a 28 day total as a current day total.

- When a number moves, say whether the move came from a new crawl, a scope change or a different date range before you call it progress.

## Available connectors

- Use `muse.connector_search` to find other connectors and `muse.skill_search` to find related skills.

- If nothing here fits, look on the web for a maintained API or MCP server and set it up with [Custom Connectors and MCPs](/opt/muse/skills/custom-connector-setup/SKILL.md), or build a custom connector.

## Websites

- [Google Search Console](https://search.google.com/search-console/) for the Pages view, the sitemap view and the last crawl date. Carry the property name and the exact view into the browser task and verify the numbers on the page itself.

## Alternatives for better results

- Ask the user to paste the exact export or screenshot when you cannot open the property, and quote from that export with its view named.

- Track the sitemap view and the property view side by side over time so a scope gap shows up as a gap rather than as a contradiction.
