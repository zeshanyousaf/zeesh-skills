# Zack D. Films Style — AI Skill

A production skill that teaches an AI assistant to make **3D animated fact shorts in the Zack D. Films format**: one strange question, a locked character acting out the explanation, macro cutaways of the hidden mechanism, chunk captions, and a reveal ending.

Built from a full frame-by-frame analysis of a real Zack D. Films Short ("How A Hidden Bookshelf Door Works 🤔", Nov 2026) — every shot, camera move, caption break and mechanism reveal documented second by second.

## How to use

1. Copy the `zack-d-films-style` folder into your AI agent's skills directory.
2. Ask the agent for a fact short "in the Zack D. Films style" — it reads `SKILL.md` and builds to that format.
