# Zeesh Skills

**Practical AI assistant skills, built from real daily production work — not theory.**

These are the working playbooks of **Zeesh Creatives**, a one-person digital business from Pakistan that publishes books on Amazon KDP, runs faceless YouTube channels, produces short-form video series, and sells digital products — all operated with an AI assistant, on a zero budget.

Every skill in this repo exists because something was learned the hard way: a mistake that must never repeat, a platform limit that cost a day's work, or a workflow that finally clicked. They are written for AI agents that support the `SKILL.md` format.

## How to use

1. Copy any skill folder into your agent's skills directory (for example `~/workspace/custom-skills/` or your agent's equivalent).
2. Each folder's `SKILL.md` is the playbook — the agent reads it when a matching task comes up.
3. Adapt names, channels and accounts to your own setup; the discipline inside is the reusable part.
