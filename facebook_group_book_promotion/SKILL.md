# Facebook Group Book Promotion

## Check the group before you prepare a post

- Read the group rules, recent posts and comment activity before you prepare a post, and prepare a post only where readers comment on book posts and where promotion is allowed.

- Skip a group that bans promotion, deletes self promotion, charges for promotion or shows no recent reader comments, and name the skipped group and the reason in your report.

- Recommend only a large active group that fits the book, and check the member count and recent activity through the Facebook connector rather than trusting the name alone.

- Vary the post text for each group so no two groups receive identical copy, and keep the book title, the hook and the link the same while you change the opening line and the description.

## Verify the Page identity route and the Amazon link

- Confirm the book live Amazon link from the KDP Bookshelf before you write the post, and use the Kindle ASIN in the form https://www.amazon.com/dp/ASIN.

- Never substitute a Gumroad link or any other store link when the Amazon link is missing, and stop that book post and report the missing link instead.

- Stop at the KDP policy gate about automated access when it appears, and hand that step to the user instead of continuing.

- Tell the user to open the group composer on their own device and check that the posting identity shown there is the managed Page before typing the post.

- Mark a group as skipped when the composer shows the personal profile with no way to switch to the Page, and report the group as skipped for that reason.

- Never post a group book post as the personal profile, and never use the Facebook connector to post in a group because the connector post goes out as the personal profile.

- Do not sign in to Facebook in the agent browser to post in a group, and hand the prepared pack to the user on their own device instead.

## Hand the user a ready to post pack

- Prepare the approved text, the image and the verified Amazon link as one pack for the user to post on their own device, and name the group and the Page in the pack.

- Ask the user for the live post link after posting, and read the live post back through the Facebook connector when the user shares its link to check that the author is the Page and the link opens the right Amazon page.

- Record the live post link, the group and the posting identity for each post, and report a pending approval separately from a live post.

- Tell the user to delete a post that went out as the profile as soon as you find it, and to repost it as the Page only where the group allows it.

- Stop preparing posts for a book in a group that removes the post or shows hostility to AI books, and do not prepare the same copy there again.

## Websites

- [Facebook](https://www.facebook.com/) for posting in a group as the Page on the user own device. Carry the approved text, the image, the verified Amazon link and the Page name into the pack for the user, and tell the user to check the posting identity in the composer before submitting and to share the live post link after publication.

- [KDP](https://kdp.amazon.com/) for confirming the book live ASIN and price on the Bookshelf. Carry the book title into the check and use only an ASIN shown as Live. Stop if the KDP sign in shows a policy gate about automated access, and hand that step to the user instead of continuing.

## Alternatives for better results

- Ask the user which groups matter most when several groups fit, so the strongest audiences get the post first.

- Prepare one book per group per run and space reposts across days, so the posts read as separate recommendations rather than a blast.

- Tell the user to check the post comments the next day, since a reply from the Page keeps the post visible longer.
